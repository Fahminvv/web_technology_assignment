Client/Server

Definition of Client

A client is a computer or device that requests services or information from a server. A web browser is an example of a client.

Definition of Server

A server is a computer or program that provides services, information or resources to clients through a network.

Components of Web Application

View Layer

The View Layer is the part of a web application that the user can see and interact with. HTML, CSS and JavaScript are commonly used in this layer.

Business Layer

The Business Layer contains the main rules and logic of the application. It processes the data received from the user.

Data Access Layer

The Data Access Layer is responsible for communicating with the database. It is used to store, retrieve and update data.

Types of Web Content

Text

Text is used to display information, headings, paragraphs and other written content on a webpage.

Images

Images are used to make webpages more attractive and to present information visually.

Audio

Audio content includes music, sound effects, voice recordings and other sounds.

Video

Videos can be used to show lessons, demonstrations, advertisements and other information.

Animation

Animation is used to create moving elements on a webpage. It can make a webpage more interesting and interactive.

HTTP and HTTP Request

Definition of HTTP

HTTP stands for HyperText Transfer Protocol. It is a protocol used for communication between a web browser and a web server.

HTTP Request and Response

An HTTP request is sent by the client to ask for a resource from the server. The server processes the request and sends back an HTTP response.

Working of HTTP Communication

First, the user enters a web address in the browser. The browser sends a request to the server. The server processes the request and sends the required information back to the browser.

Dynamic Web Pages

Definition

A dynamic web page is a webpage whose content can change based on user input, time, database information or other conditions.

Characteristics

  • Content can change automatically.
  • Can interact with users.
  • Can use database information.
  • Provides personalized content.

Examples

Examples include online shopping websites, social media websites, online banking websites and webmail services.

Application Servers

Definition

An application server is software that provides an environment for running web applications and their business logic.

Purpose

The main purpose of an application server is to manage and run applications and connect them with databases and users.

Major Services

  • Application management
  • Database connection
  • Security
  • Transaction management
  • User management

Web Security

Definition

Web security means protecting websites, web applications and user information from unauthorized access and attacks.

Importance

Web security helps to protect personal information, passwords, financial information and other important data.

Basic Security Measures

  • Use strong passwords.
  • Use HTTPS for secure communication.
  • Keep software updated.
  • Use authentication and authorization.
  • Protect databases from unauthorized access.
